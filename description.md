**tmux**

tmux is a terminal multiplexer. This plugin installs a static build of tmux, so it does not depend on the libraries of the Unraid base.

The package also installs the terminfo entries `tmux`, `tmux-256color`, `screen` and `screen-256color`, because the Unraid base does not have them.

For more information see the [tmux repository](https://github.com/tmux/tmux) and the [build-static-tmux repository](https://github.com/mjakob-gh/build-static-tmux).
